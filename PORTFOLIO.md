## Portfolio rules

- A repository is not presented as proof of an entire product when only a subsystem or export is public.
- Client/company source is only included when it has been explicitly sanitized for public review.
- Historical snapshots are labeled as historical.
- Duplicate repositories are consolidated in presentation; IGame-PWA is the primary public reference for the IranCP PWA snapshot.
- Public visibility is not treated as a license to reuse third-party or client material.
